# Pediatric Clinical Guidance

NOTE: Reference ranges should be verified by clinical team before use.

## Age Formatting
- For patients >24 months, report age in years (not months)
- For patients ≤24 months, report age in months

## Routine Care (Do NOT Nudge)
- Standard well-child visit components are routine for pediatricians
- Developmental screening is part of standard workflow
- Anticipatory guidance is standard practice
- Future vaccine scheduling is not a care gap

## Reference Ranges (Verify with clinical team)

The following are examples - verify before clinical use:
- Infant (1-12mo) HR: 100-150 bpm (lower values are concerning)
- Infant RR: 30-60 breaths/min
- Weight-for-length 5th-95th percentile is NORMAL

## Growth Percentiles
- 5th-95th percentile is normal range for weight-for-length
- Do not flag values within this range as concerning
- Only flag if below 5th or above 95th percentile
